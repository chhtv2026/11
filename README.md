# Земля в аренду

Реестр земельных возможностей: источники (фонды перераспределения, реестры, перечни)
и участки-кандидаты со статусами и правовыми выводами. Пилот — Псковская область.

План работ и решения — в [PLAN.md](PLAN.md).

## Как запустить

В папке проекта:

```bash
npm run dev
```

Затем открыть в браузере http://localhost:3001 (порт 3001, чтобы не мешать приложению идей на 3000).

## Загрузка готовых наборов участков

В папке `seed/` лежат подготовленные наборы. Пока приложение запущено, в другом окне:

```bash
npm run import -- seed/pskov-fund-2024-07-16.json
```

Повторный запуск ничего не дублирует: участки с уже известным кадастровым номером пропускаются.

## Где хранятся данные

В файле `data/registry.json` на этом компьютере. Он **не** отправляется на GitHub —
копию стоит время от времени сохранять вручную.
